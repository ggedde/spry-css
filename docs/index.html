SpryCSS

SpryCSS

SpryCSS aims to be a simple, lightweight and dependency free CSS Toolkit, but can be customized with a sass compiler if needed.
The goal is to remove the messy and tedious task of coming up with class names for elements that just need simple layout styles and provide basic components to help you get up and running fast, but not try to do everything which can bloat your project.
It is almost inevitable that you will need to add your own custom css and therefore it should be simple and easy to do without conflicts. SpryCSS does not use !important and tries to use the lease amount of css priority as possible.

Installation

Compatibility

SpryCss uses modern css properties and native css nesting which is supported by all major browsers since April 2024

Using the CDN:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ggedde/spry-css@3.0.0-rc.2/dist/spry.min.css">

Using a package manager:

npm
npm install @ggedde/spry-css
Yarn
yarn add @ggedde/spry-css
Bun
bun install @ggedde/spry-css

Then in your scss file import SpryCSS:

@import 'node_modules/@ggedde/spry-css/spry.scss';

Note: you may need to change the path to match your project's node_modules folder

To override the Spry Variables just declare the variables before you import the file. 

@import 'your_variables.scss';

SpryJS Javascript Optional

SpryCSS is meant to be quick and easy to implement without needing to add any additional dependencies. However, there are times when you need more functionality then CSS can offer. For this reason, you can include SpryJS to handle Toggles and Sliders. Toggles add additional functionality for many of its components like Accordions, Buttons, Lists, Menus, Modals, and Tabs. SpryCSS also comes with basic Sliders that have limited functionality, but you can add SpryJS for more functionality.

SpryJS

<script defer src="https://cdn.jsdelivr.net/gh/ggedde/spry-css@3.0.0-rc.2/dist/spry.min.js"></script>
The SpryJS file will run the following functions on document page load.

Load Functions
Spry.loadToggles() Loads all Toggles into scope and runs all necessary features.
Spry.loadSliders() Loads all Sliders into scope and runs all necessary features.
Spry.loadLists() Loads all Lists into scope and runs all necessary features.
Additional Functions
Spry.toggle(toggleObjectOrEvent, forceAction)

Toggles the class open on an element if it has been registered with data-toggle. See Toggles for more information.

toggleObjectOrEvent - Can be a valid css selector, element object, or event of element object.

forceAction - Can be close, open or toggle (default)
Spry.closeToggle(toggleObjectOrEvent)

Closes a toggle element. See Toggles for more information.

toggleObjectOrEvent - Can be a valid css selector, element object, or event of element object.
Spry.closeAllToggles()

Closes all toggle elements on the page. See Toggles for more information.

Accessing Variables in SCSS

You can access variables using map-get()

@use "sass:map";

p {
    color: map.get($colors, 'default', 'primary');
    background-color: rgba(map.get($colors, 'default', 'primary'), .5);
    margin-bottom: 1rem;
    @media screen and (min-width: map.get($breakpoints, 'md')) {
        margin-bottom: .5rem;
    }
}

Breakpoints

SpryCSS is mobile first. Meaning all styles start from the smallest device then allow for changes with min-width using breakpoints.
By default, SpryCSS only comes with one breakpoint md at 40em.

You can add more breakpoints in the SCSS Variables, but keep in mind that the more breakpoints you add the larger the compiled file size will be.

SCSS Variable 
$breakpoints: (
    md: 40em,
)

Media Queries

To use media queries use the prefix {breakpoint}: with allowed component classes. See below for which components classes use media queries.

<div class="p-4 md:p-2">

Container Queries

To use conatiner queries use the prefix c-{breakpoint}: with allowed component classes. See below for which components classes use container queries.

Container queries require a wrapping element that has container-type: inline-size;. You can use the class container to add this to a parent element.

<div class="container">
    <div class="p-4 c-md:p-2"></div>
</div>

Containers with container-type: inline-size; will break the position of any child elements. This will break modals and other elements if placed inside. If this is not desired then you will need to place those elements outside the container element.

Used In
Borders Borders allow breakpoints. ex <div class="b-0 md:b-2">No Border on Mobile</div>
Gaps Gaps uses breakpoints to define initial margin in <hr> and initial padding in <section>
Grid Grid uses gaps in CSS Grid and CSS Flexbox grids
Sizing Spacing allows breakpoints. ex <div class="sm md:lg">Small on Mobile, Large on Medium</div>
Spacing Spacing allows breakpoints. ex <div class="p-0 md:p-2">No Padding on Mobile</div>
Layout Utility Classes Layout Utility Classes allow breakpoints. ex <div class="none md:block">Hide on Mobile</div>

Checked Classes

Checked Classes apply to the siblings of an element. Like :has(:checked) > .checked:none.
This allows you to swap labels or elements based on the state of a checked or unchecked sibling.

Example:

<label>
    <input type="checkbox">
    <span class="none checked:revert">On</span>
    <span class="checked:none">Off</span>
</label>

Icons

SpryCSS doesn't come with its own icon package. You can use whatever ican package or icon webfont you want, but icon webfonts can greatly increase the size of your projects. A recommended alternative is to use direct svg code within your project. This produces the smallest file size while producing high resolution icons and allowing you the most flexibility to style the icons within your css.

A great option for this is Material Design Icons or Material Design Icons Light. You can search for icons and view the SVG code by clicking on the Code dropdown and click on 'View SVG'. Then copy and paste the code in your html.

If your using Visual Studio Code you can install the extension vscode-materialdesignicons-svg that provides code snippets to quickly add the SVG code.

    Sliders

    These are basic lightweight sliders. If you are looking for something more robust, you might want to check out Swiper or Glide

    You can add loading="lazy" to the images, but it may be a little choppy when scrolling on some browsers. The Slider will detect the lazy loading images and pre load them on the next and previous slides when using SprySliderJS. If you want a smooth transition it is best to load all the images initially.

    <!-- Slider No JS -->
<div class="slider" data-snap>
    <div class="slider-slides">
        <img id="no-js-slide1" src="/placeholder-1.jpg" loading="lazy">
        <img id="no-js-slide2" src="/placeholder-2.jpg" loading="lazy">
        <img id="no-js-slide3" src="/placeholder-3.jpg" loading="lazy">
    </div>
</div>

    Data Options
    data-snap Forces stopping on each slide even when using grid layout. This is not forced with momentum scrolling.
    data-loop Allows the Slides to Loop. Requires SprySliderJS
    data-play="{n}" Enable autoplay in miliseconds. Requires SprySliderJS
    data-stop="{enum}" Pauses Autoplay. Requires SprySliderJS

    Options:

    • hover - Pause autoplay while hovering over slider
    • action - Pause autoplay while hovering over a link, button or making a text selection within slider.
