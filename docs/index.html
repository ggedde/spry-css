SpryCSS

SpryCSS

SpryCSS aims to be a simple, lightweight and dependency free CSS Toolkit, but can be customized with a sass compiler if needed.
The goal is to remove the messy and tedious task of coming up with class names for elements that just need simple layout styles and provide basic components to help you get up and running fast, but not try to do everything which can bloat your project.
It is almost inevitable that you will need to add your own custom css and therefore it should be simple and easy to do without conflicts. SpryCSS does not use !important and tries to use the lease amount of css priority as possible.

SpryJS Javascript Optional

SpryCSS is meant to be quick and easy to implement without needing to add any dependencies or javascript. However, there are times when you need more functionality. You can use your own Javascript or any Javascript framework you like. You can also use SpryJS which works well with SpryCSS for additional functionality like Navigable, Observe, Parallax, ScrollSpy, Sliders, Toggles, Cookies, Hash, and Query.

SpryCSS also comes with basic css only Sliders and Toggles that have limited functionality, but you can use SpryJS to extend them.

Compatibility

SpryCSS uses modern css properties and native css nesting which is supported by all major browsers since April 2024

If you need support for older browsers, then SpryCSS might not be the best choice for you.

CSS Configuration

CSS Variables

Certain variables change based on specific scopes or conditions. Overriding them via CSS may require overriding all scopes or conditions, like each breakpoint. Therefore, it's best to override these variables in SASS.

Accessing Variables in CSS

* Unfortunately, CSS Variables do not work in Media or Container Queries (yet). Instead it is recommended to use a Pre-Processor like SASS/SCSS.

SCSS Configuration

To override the Spry Variables just declare the variables before you use the file(s) and use the @forward rule in your custom variables file.

Themes

SpryCSS includes a default theme, but custom themes can be added using SCSS variables. Each theme can use light-dark() to specify distinct colors for both light and dark modes. Custom theme values override defaults, while unspecified values automatically inherit from the default.

SCSS Variable

See below for an example of how to define a custom theme.

Classes
.theme-{name}

Set Custom Theme.

This changes the entire element and child elements to the specified theme.
.scheme-light

Force Light Scheme

This changes the entire element and child elements to light scheme.
.scheme-dark

Force Dark Scheme

This changes the entire element and child elements to dark scheme.
.scheme-toggle

Toggle Light/Dark Scheme based on user preference

This changes the entire element and child elements to the opposite of user's preferred scheme.

Only works if theme supports both light and dark schemes.

Collapse

Elements can be made collapsible by applying the collapse class. Their visibility state is managed by the open class. Additionally, SpryCSS provides state utilities such as c:open, f:open, or h:open, which can be applied directly to the collapsible element or its parent to control its open state. For interactive control, Toggles can also be used.

* Requires a single nested element

Components that can use collapse:
Accordions Dropdowns Lists Menus Navs Tabs
If your single child element requires spacing like padding, margin, or borders, then it is best to wrap it with an empty container.
Classes
{breakpoint}:collapse

Initiate the element in the collapsed state and animates height when opened. open always has priority, but if you use breakpoints you must match or beat with a breakpoint.

* Requires a single nested element

* This will be updated to use calc-size(auto) when browsers fully support it.
{breakpoint}:open Opens the element at breakpoint
{breakpoint}:c:open Opens the element when a sibling or toggle is or contains a checked element. Opens all children that have collapse. See Checked for more information.
{breakpoint}:f:open Opens the element on focus-within. Opens all children that have collapse.
* Is dismissible without javascript. See Focus for more information.
{breakpoint}:h:open Opens the element on hover or focus-visible. Opens all children that have collapse or hidden nav items. See Hover for more information.
{breakpoint}:overlay Overlays the element on top of the other content. This is an alias for using relative and absolute containers and adds a few other styles making it easy to use.
{breakpoint}:from-default Subtle animation from the top. (Default)
{breakpoint}:from-top Animates the element from the top.
Best when used with overlay to prevent overlapping content when animated.
{breakpoint}:from-start Animates the element from the start.
Best when used with overlay to prevent overlapping content when animated.
{breakpoint}:from-end Animates the element from the end.
Best when used with overlay to prevent overlapping content when animated.
{breakpoint}:from-bottom Animates the element from the bottom.
Best when used with overlay to prevent overlapping content when animated.

fast Sets the transition to a faster speed

Breakpoints

SpryCSS is mobile first. Meaning all styles start from the smallest device then allow for changes with min-width using breakpoints.
By default, SpryCSS only comes with one breakpoint md at 40em.

You can add more breakpoints in the SCSS Variables, but keep in mind that the more breakpoints you add the larger the compiled file size will be.

SCSS Variable

// Specify each breakpoint size // Adding breakpoints will increase bundle size so add cautiously. $breakpoints: ( md: 40em, // lg: 80em, );

Media Queries

To use media queries use the prefix {breakpoint}: with allowed component classes. See below for which components and utilities use breakpoints.

<div class="p-4 md:p-2">

Container Queries

To use container queries use the prefix @{breakpoint}: with allowed component classes. See below for which components and utilities use breakpoints.

Container queries require a wrapping element that has container-type: inline-size;. You can use the class @container to add this to a parent element.

<div class="@container"> <div class="p-4 @md:p-2"></div> </div>

Containers with container-type: inline-size; will break the position of any child elements. This will break modals and other elements if placed inside. If this is not desired then you will need to place those elements outside the container element.

Icons

SpryCSS doesn't come with its own icon package. You can use whatever icon package or icon webfont you want, but icon web-fonts can greatly increase the size of your projects. A recommended alternative is to use direct svg code within your project. This produces the smallest file size while producing high resolution icons and allowing you the most flexibility to style the icons within your css.

A great option for this is Material Design Icons or Material Design Icons Light. You can search for icons and view the SVG code by clicking on the Code dropdown and click on 'View SVG'. Then copy and paste the code in your html.

If your using Visual Studio Code you can install the extension vscode-materialdesignicons-svg that provides code snippets to quickly add the SVG code.
