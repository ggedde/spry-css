# SpryCSS Rules and Conventions

## Css
- This project is SpryCSS v3, which you can review the docs here for now: docs/index.html.
- SpryCSS is simple and customizable CSS Toolkit while being as lightweight as possible.
- A full minified file of SpryCSS that you can review to see what classes are available is here: dist/spry.min.css.
- Don't use or suggest Tailwind or any other css framework classes. Only use and suggest SpryCSS classes.

## SpryJS v1.0.2
- SpryJS is a helper javascript toolkit similar to jQuery, but a lot different.
- You can use SpryJs for Dom queries, fetching and setting cookies, and supplying toggles to dom elements.
- You can review SpryJS here: https://ggedde.github.io/spry-js
- There are many ways to use SpryJS, but for this project we have already included it in public/assets/spry.js and pulled it in our <head> so it is already available.
